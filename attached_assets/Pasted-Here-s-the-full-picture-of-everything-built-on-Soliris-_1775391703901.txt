Solana MCP Server · Frontier Hackathon submission · Deadline May 11

WHAT IT IS
An x402-native Solana MCP server that runs a fully autonomous copy-trading agent on Solana mainnet. It scans tokens, makes AI decisions, executes real Jupiter swaps on-chain, and logs every decision to the Solana Memo program so anyone can verify the agent's reasoning publicly. Dual revenue model: $0.001 USDC x402 fee per tool call + 0.2% Jupiter platform fee per swap.

ARCHITECTURE
3 services running in parallel:

api-server — Express backend, agent loop, all trading logic, x402 payment handler
soliris (frontend) — React + Vite Command Center dashboard
mockup-sandbox — Component preview server for UI design iteration
Stack: Node.js · TypeScript · Express · @solana/web3.js · Jupiter Aggregator · React · Tailwind · React Query · Pino logging

AUTONOMOUS TRADING ENGINE
Dual-source scanner running every 90 seconds:

DexScreener — filters tokens: age <180min, liquidity >$3K, volume/liquidity ratio >1.2x
Pump.fun on-chain — catches pre-graduation hot mints with ≥3 buys, ≥1 SOL volume before they hit DexScreener
Brain scoring — every candidate token is scored on:

Signal source win rate
Token age bucket performance (best: 1–6hr window at +69.8% avg)
Smart money wallet overlap (BURNIE cluster detection)
Volume/liquidity ratio, price momentum, early buyer history
Execution pipeline (live mode):

Jupiter quote → simulate → sign → send
Decision logged to Solana Memo program (pre-commitment, before swap fires)
Both txs have Solscan links visible in real-time
Safety rails:

0.02 SOL max per trade
3 concurrent positions max
5% price impact hard cap
Simulate before every send
Circuit breaker: 3 consecutive losses → auto-pause, manual reset required
ON-CHAIN DECISION LEDGER (Hackathon differentiator)
Every buy/sell decision is logged to the Solana Memo program as a JSON blob before the swap executes. This means:

The agent's reasoning is publicly verifiable on-chain
Judges can compare the decision log tx timestamp vs the swap tx — agent committed first, then traded
Solscan links for both txs appear live in the dashboard
/api/agent/decision-ledger endpoint exposes the full in-memory ledger

x402 PAYMENT PROTOCOL
Every MCP tool call requires a $0.001 USDC micropayment via the x402 protocol. The server:

Verifies payment headers on every tool invocation
Tracks cumulative USDC volume in real-time
Currently at 0 (no external agents calling yet — npm package needs discovery)
REVENUE MODEL (two streams)
x402 protocol fees — $0.001 USDC per tool call. At 1,000 calls/day = $1/day. Scales with agent adoption.
Jupiter platform fees — 0.2% of every swap routed through the agent. At 10 SOL/day volume = 0.02 SOL/day.
Both configured via env vars: PLATFORM_FEE_BPS=20, PLATFORM_FEE_ACCOUNT (still needs to be set for Jupiter fees to collect).
