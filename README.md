# Toolora

[![Listed on toolora.dev](https://toolora.dev/api/directory/badge/toolora-private.svg)](https://toolora.dev/mcp-hub)

Privacy-first browser-based tools + an app store for MCP servers.

- **[toolora.dev](https://toolora.dev)** — 100+ free, client-side tools (PDF, image, text, dev). Nothing leaves your browser.
- **[toolora.dev/mcp-hub](https://toolora.dev/mcp-hub)** — 340+ Model Context Protocol servers, with one-click install configs for Claude, Cursor, Windsurf, VS Code, and Continue.
- **[toolora.dev/agents](https://toolora.dev/agents)** — `agents.json`, the machine-readable MCP directory agents can read.
- **[toolora.dev/private](https://toolora.dev/private)** — paid tier: run private MCP tools against your own files, locally.

## For MCP server authors

List your server free at **[toolora.dev/mcp-hub/submit](https://toolora.dev/mcp-hub/submit)** and get:

- A live install counter, broken down by client (Claude / Cursor / Windsurf / …)
- A free analytics dashboard at `/mcp-hub/owner/{your-slug}` — 7-day and all-time installs, badge impressions, top referrers
- An embeddable badge for your README:

  ```markdown
  [![Listed on toolora.dev](https://toolora.dev/api/directory/badge/YOUR-SLUG.svg)](https://toolora.dev/mcp-hub/server/YOUR-SLUG)
  ```

- Inclusion in the agent-readable feed at `/api/directory/agents.json`, sorted by quality (featured → 30-day installs → recency) so agents pick the best server without scraping HTML.

## Why Toolora

Built and run from Lagos. Crypto-first monetization (USDC on Solana) so it works in markets Stripe doesn't. Privacy-first because regulators in every market are about to make that the table-stakes default — we're just early.
